## 9 One sentence user stories

Every story below is one sentence with a user action and a benefit. Acceptance details are defined in the surrounding requirements and the release scenarios. IDs are stable for implementation tracking.

### Starting and access

| **ID** | **Priority** | **One sentence story** |
| --- | --- | --- |
| US01 | P0 | As a first-time learner, I can start in an empty room so that I can practice without props or special furniture. |
| US02 | P0 | As a complete beginner, I can say that I know no Japanese so that Sensei begins without assuming vocabulary or literacy. |
| US03 | P0 | As an experienced learner, I can begin advanced Japanese conversation immediately so that beginner lessons do not block me. |
| US04 | P0 | As a learner, I can move and resize my practice area so that the experience fits my available space. |
| US05 | P0 | As a learner, I can practice seated or standing so that I can use a comfortable position. |
| US06 | P0 | As a learner, I can begin without creating an account so that I can reach the experience quickly. |

### Spoken conversation

| **ID** | **Priority** | **One sentence story** |
| --- | --- | --- |
| US07 | P0 | As a learner, I can speak naturally to Sensei and hear its answer so that I can practice actual conversation. |
| US08 | P0 | As a learner, I can mix English and Japanese so that missing vocabulary does not end the exchange. |
| US09 | P0 | As a learner, I can ask an unanticipated follow-up question so that Sensei addresses what I actually need to understand. |
| US10 | P0 | As a learner, I can change topic or choose conversation only so that I am not trapped in an activity. |
| US11 | P0 | As a learner, I can see whether Sensei is listening, processing, or speaking so that turn-taking is clear. |
| US12 | P0 | As a learner, I can interrupt with the talk control so that I can correct or redirect Sensei promptly. |
| US13 | P0 | As a learner, I can replay a spoken example so that I can hear it again without restarting the conversation. |
| US14 | P0 | As a learner, I can request slower speech so that I can follow a difficult utterance. |

| US16 | P0 | As a learner, I can recover from a connection problem so that my progress and current activity remain available. |

### BYOK and the game master

| **ID** | **Priority** | **One sentence story** |
| --- | --- | --- |
| US52 | P0 | As a player, I can enter my own Meta API key so that I can use the experience without an application-operated server. |
| US53 | P0 | As a player, I can test my provider connection and understand an authentication or quota error so that I can resolve setup before a lesson. |
| US54 | P0 | As a player, I can replace or clear my credentials without deleting learning progress so that I control access independently of my profile. |
| US55 | P0 | As a learner, I can ask Sensei to create or change an activity so that its game-master tools adapt the scene to my current goal. |
| US56 | P0 | As a learner, I can hear feedback that matches completed game actions so that Sensei does not claim an object moved when it did not. |
| US57 | P0 | As a learner, I can interrupt queued Sensei actions so that I retain control when my intention changes. |
| US58 | P0 | As a builder, I can inspect a redacted tool trace so that I can explain how Sensei's decisions produced each game action. |

### Speech synthesis on the headset

| **ID** | **Priority** | **One sentence story** |
| --- | --- | --- |

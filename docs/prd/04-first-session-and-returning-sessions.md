## 4 First session and returning sessions

### Provider setup

Before the first learning session, the player enters one Meta Model API key in a masked settings field and tests the connection. A separate local voice check initializes the bundled TTS assets and speaks Japanese and English without a synthesis account, key, or runtime download. The Meta key remains in memory for the current app session. For the judge demonstration, the demonstrator completes setup before handing over the headset; setup does not consume the beginner teaching sequence.

### A learner with no Japanese

1. Welcome: Sensei appears, introduces itself in English, and asks about prior knowledge. The learner can say, 'I know no Japanese,' or select an equivalent button.

2. Place the practice area: a comfortable floating area is supplied automatically; the learner may reposition it. No physical table is required.

3. Establish meaning: show one water object. Sensei says 'mizu' and explains that it means water. Japanese text, reading, romaji, and meaning are independently configurable.

4. First spoken success: Sensei models 'Mizu o kudasai.' The learner can repeat, use just 'mizu,' ask why, or request slower speech. Sensei responds to the communicated meaning and marks the help used.

5. A genuine exchange: answer an unanticipated relevant question, such as 'Why is that o and not wo?' The answer refers to the current phrase and is spoken aloud.

6. Add contrast: introduce tea, rearrange the two items, and invite the learner to identify or request one without automatically revealing the answer.

7. Try with less help: offer a new request with the full model answer hidden. The learner can restore help immediately.

8. Summarize honestly: state which expression was practiced, what the learner did with support, and whether any independent use was demonstrated.

Do not treat the opening as a speed test or claim fluency after one interaction. The first useful outcome should arrive early, but silence and hesitation must be supported rather than penalized.

### An advanced learner

The learner selects Advanced or says that they want advanced Japanese practice. Sensei starts in Japanese and asks a substantive question using the current scene. For example, the learner must choose items for a guest, explain competing preferences, clarify a constraint, and reformulate a request politely. Sensei responds to the learner's reasoning rather than following a fixed dialogue tree.

### A returning learner

Restore preferences and previous skill evidence, then offer a brief choice: continue the recent topic, revisit something uncertain, or start a new conversation. Include a delayed fresh attempt on earlier language when appropriate. Reposition the practice area if necessary; never depend on a persistent physical-room map.

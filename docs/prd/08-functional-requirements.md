## 8 Functional requirements

| **ID** | **Requirement** | **Pri.** |
| --- | --- | --- |
| FR01 | Launch directly into a configurable passthrough practice space with a visible ghost red panda and no physical-prop requirement. | P0 |
| FR02 | Complete a voice round trip with remote Meta recognition and reasoning plus audible Japanese and English synthesis on the Quest. | P0 |
| FR03 | Support unscripted multi-turn conversation, relevant follow-up questions, mixed-language input, and a change of topic. | P0 |
| FR04 | Resolve pointing, named objects, recent references, and ambiguous pronouns against the current scene. | P0 |
| FR05 | Execute validated scene changes using only bundled pre-rendered assets, accepting multiple natural expressions of the same intent. | P0 |
| FR06 | Provide all five starting bands, user-controlled difficulty, and substantive advanced conversation immediately. | P0 |
| FR07 | Offer contextual help, repeat, slow speech, translation, a partial phrase, a full model, and demonstration. | P0 |
| FR08 | Generate bounded activity variations, validate them before use, and check world outcomes independently of dialogue. | P0 |
| FR09 | Distinguish independent performance, assistance, language errors, interaction mistakes, and unresolved input. | P0 |
| FR10 | Persist preferences, learning evidence, and next-practice suggestions across app restarts. | P0 |
| FR11 | Cancel speech and stale requests, recover from service failures, and avoid duplicate scene actions. | P0 |
| FR12 | Provide a session summary, reset controls, and a removable local profile without mandatory registration. | P0 |
| FR13 | Support direct hand interaction once its reliability matches the controller path. | P1 |
| FR14 | Add extra validated objects, explanation languages, and cosmetic rewards without changing progression rules. | P1 |
| FR16 | Accept, test, replace, and clear one player-supplied Meta key and call Meta APIs directly without an application backend or TTS credential. | P0 |
| FR17 | Run the conversation loop and typed tool registry in C#; every Sensei-directed game effect must have a validated call and actual result. | P0 |
| FR18 | Verify the chosen C# library, serialization, tool dispatch, and cancellation in a Quest Android IL2CPP build. | P0 |
| FR19 | Bundle an offline Japanese and English synthesis runtime and model assets; generate novel spoken text locally with no synthesis network calls. | P0 |
| FR20 | Run local synthesis away from the Unity main thread and stop playback or discard obsolete output without compromising interaction or rendering. | P0 |

# Three-minute headset demo

Record with the Quest's built-in recording in passthrough, with one person wearing the headset and using both controllers. Start with a fresh learner profile, a working connection and key, and a clear view of the practice area. Record the actual speech and captions. Sensei's replies are generated, so the lines below are the demonstrator's exact prompts, not promised replies; keep a take only if the requested outcome appears. Do not reset progress before the return visit.

The durations below are the **edited** timeline, including the intro and outro: **3:00 total**. Real turns have taken roughly 10–25 seconds. At each marked cut, wait for the actual response while recording, then remove the idle interval in editing. Label each jump “Wait shortened”; keep the full spoken prompt and resulting response/action, and never imply the reply was instant. Record a fresh take if recognition or the task fails; do not splice in a different outcome.

## Voice-over

**Intro, 0:00–0:15:** “This is Red Panda Sensei: Japanese practice in your own room. A red panda helps you learn words and use them with objects you can see.”

**Outro, 2:45–3:00:** “Your progress stays on the headset, so Sensei can welcome you back. Try a word, ask for help, and continue the conversation at your own pace.”

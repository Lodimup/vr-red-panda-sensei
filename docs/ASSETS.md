# Asset provenance

All images in `assets/sprites/` were generated for this project with an image model via ChatGPT. No third-party photographs were used. Sensei's poses use one character reference for visual consistency. The object set comprises apple, bag, banana, book, box, cup, key, pen, rice ball, tea, umbrella and water; the Sensei set comprises idle_float, listen, think, speak, point, encourage and demonstrate. Each set includes a source PNG and a corresponding `_card.png` for every entry. The card treatment adds a printed border and visible cardboard edge around the transparent cutout, making a flat die-cut standee for the tabletop; the source and card files and their SHA-256 lists are kept together in each directory.

The ASR test corpus is generated by `tools/unity/make-asr-corpus.sh` using macOS `say` Japanese and English voices. Mixed phrases join separately synthesized language segments. These are synthetic test recordings, not human speech. The script writes to the voice spike's StreamingAssets, not the app's StreamingAssets. The app's model-fetch script adds model files and notices; test WAVs are not included by that script. A developer can deliberately add a test WAV to the app's StreamingAssets before building, in which case it is bundled in that build.
